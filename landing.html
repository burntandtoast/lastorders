Why it isn't just find-and-replace

Swapping the model name looks like a five-minute job. Usually it's mostly that, plus the bits that break quietly.

Tool calls can stop working

On Chat Completions, the January replacement gpt-6-luna only supports function calling when reasoning_effort is set to none. The default is medium. Change only the model string and your tool calls break. The fix is a code change, or a move to the Responses API.

Fine-tunes have no direct replacement

gpt-6-luna can't be fine-tuned. Your fine-tuned model is switched off with its base model on 14 January, and new fine-tuning jobs stop on 6 January. You need a plan before then, not a patch afterwards.

Outputs drift

A new model answers slightly differently. JSON fields get renamed, a classifier sorts things into different buckets, a summary runs longer. Nothing errors, but something downstream does the wrong thing.

Model IDs hide everywhere

Config files, environment variables, database seeds, test fixtures, settings migrations, docs your users copy. The ones you forget about turn up on shutdown day.

Undated aliases

gpt-4o or gpt-4.1-mini with no date still resolves to a snapshot on the list. We don't guess the date from the alias alone; the free scan confirms which snapshot you're on.

Nobody has time this quarter

The deadline lands in the middle of everything else, including Christmas. Fair enough. That's what we're for.

Questions

If yours isn't here, email us. A person reads it.

We use a fine-tuned GPT-4o or GPT-4.1 model. What happens?

Fine-tuned models follow their base model's schedule, so they're switched off on 14 January 2027. gpt-6-luna can't be fine-tuned, and new fine-tuning jobs stop on 6 January 2027. That's what the premium tier is for. We snapshot what your fine-tune does now, set out your realistic options, and measure the one you pick against those snapshots. Get in touch early, because some routes need that 6 January date.

What do you do with our code and data?

We work on a copy of your repository or on a branch you give us. Nothing goes to production unless you merge it. We run the tests with your API key or a test key you provide, and we don't keep your code, prompts or outputs after handover. The snapshot set goes to you, not into our files. If you'd prefer we test on scrubbed or synthetic inputs, say so.

Can't we just change the model name ourselves?

Often you can, and if that's true for you we'll say so. The traps are tool calls on Chat Completions (which need reasoning_effort set to none on gpt-6-luna), fine-tunes, and quiet output drift. The report exists so you can see whether any of those apply to you.

We're on gpt-4.1-nano or gpt-4o-2024-05-13.

Those go on 23 October 2026, which is days away. Email us today and we'll move you up the queue. OpenAI recommends gpt-5.6-luna and gpt-5.6-sol as replacements for those two, and we'll check which suits you.

How do we know which models we actually use?

The scan finds what your code names. OpenAI's List models endpoint also shows a shutdown_date on each model, and we include both in the inventory.
