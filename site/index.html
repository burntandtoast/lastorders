Last Orders migration packs

Machine-readable data about retiring AI models (IDs, shutdown dates, replacements, parameter rules) used by lastorders, the free model-retirement scanner from Burnt & Toast Studios.

  • v1/index.json (list of packs with versions and SHA-256)
  • v1/pack.schema.json (JSON Schema for the pack format)
  • Anthropic Claude API (stub) v2026.10.22.1 (stub)
  • Microsoft Foundry partner models (Mistral, Cohere, Meta, Microsoft) v2026.10.22.1 (stable)
  • Google Gemini on Vertex AI v2026.10.16.2 (stable)
  • OpenAI API v2026.10.16.2 (stable)

Data is checked against the providers' documentation on the date in each pack. Always re-verify before acting.
